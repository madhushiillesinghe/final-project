# Southern Agro Company Management System

## Overview
This is a **Standalone IT Solution** designed for **Southern Agro Company** to help manage customers, employees, products, machines, suppliers, and expired products. The system also allows tracking of fertilizer product expiry dates and sends notifications to reduce wastage.

Key features include:
- **Customer Management**: Maintain customer details and transaction history.
- **Employee Management**: Track employee records and details.
- **Product Management**: Manage products and monitor expiry dates.
- **Supplier Management**: Keep track of suppliers.
- **Expiration Notifications**: Pop-up message 3 months before product expiry to reduce waste.
- **Password Reset**: Users can reset their password via email using a reset code.

## Technologies Used
- **JavaFX**: For creating the GUI.
- **Java**: For core logic and functionality.
- **MySQL**: For database management.
- **JDBC**: For database connection.
- **Jasper Reports**: For generating reports.
- **FXML**: For user interface design.
- **SMTP (JavaMail API)**: For sending password reset emails.
- **Maven**: Dependency management using `pom.xml`.

## Features
- **Manage Customers**: Add, update, or remove customer records.
- **Employee and Machine Tracking**: Manage employee records and machine inventories.
- **Product Expiry Alerts**: Alerts when products are about to expire, specifically fertilizers.
- **Password Recovery**: Send password reset emails with a reset code.
- **Reporting**: Generate product, sales, and employee reports using Jasper Reports.
